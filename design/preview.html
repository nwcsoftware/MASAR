Category = start border + 14 % tint. Never a full fill, so status pills and conflict rings stay readable on top.
Conflicts are the only red. Red ring on calendar blocks, red bar in the attention list, red badge in the sidebar — same meaning everywhere.
RTL is a mirror, not a flip. Sidebar moves to the right, time still reads left→right inside the calendar grid, symmetric icons stay put.
Drivers get one big button. 54 px tall, label changes with status; secondary actions are 42 px ghosts underneath.
